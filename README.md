# Tradovate-Discord-Alerts
Tradovate Discord Alerts (Chrome extension v1.2.0) Posts Tradovate fills to Discord as embedded alerts: TRADE ENTRY (green): opening or adding to a LONG or SHORT position. TRIM EXIT (pink): reducing or closing a position, with P&amp;L in points and dollars. An optional role ping goes above each alert. @everyone and @here are always blocked.
